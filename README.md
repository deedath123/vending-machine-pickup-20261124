## The line

> I've vended 12,100 snacks and never once jammed — until you walked by at 3 a.m. and my coil got stuck on the best thing in this building.

A vending machine with a perfect record — 12,100 snacks, never once jammed — meets a human at 3 a.m. and its coil finally sticks, on the best thing in the building.

## How it works

`main.py` (Python 3, standard library only) writes the line above to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`), with no trailing newline. The line is exactly 137 characters / 139 bytes (one em dash), one line.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
